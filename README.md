# 엠프코(주) 경영 대시보드

자동차 부품 무역 전문 엠프코(주)의 내부 경영 관리 웹 대시보드입니다.

## 주요 기능

| 섹션 | 내용 |
|------|------|
| 🏠 홈 | KPI 요약, 매출 차트, 재고 부족/메일/차량 현황 |
| 📧 메일 | Outlook 메일 기록 관리 (empco@outlook.kr) |
| 💰 재무 | 연도별 자산·부채·자본 현황 |
| 🚢 수출입 | 수출/수입 거래 내역 |
| 📈 매출 | 월별 매출·원가·이익률 |
| 🧾 연말정산 | 직원별 급여·세금·환급 현황 |
| 🏢 자산 | 사무동·공장 등 부동산 자산 |
| 🚗 차량 | 법인 차량 및 보험 만료 알림 |
| 📦 재고 | 부품 재고 수량·최소재고 관리 |
| 🔧 부품 스펙 | 부품 코드·단가·사양 카탈로그 |
| 🏭 거래처 | 구매·판매 업체 정보 |

## 사용 방법

1. `index.html` 파일을 웹 브라우저로 열기 (별도 서버 불필요)
2. 데이터는 브라우저 `localStorage`에 자동 저장
3. **데이터 백업**: 사이드바 하단 "내보내기" 버튼 → JSON 파일 저장
4. **데이터 복원**: "가져오기" 버튼 → 저장된 JSON 파일 선택

## 기술 스택

- 순수 HTML / CSS / JavaScript (의존성 없음)
- Google Fonts (Noto Sans KR, DM Mono)
- 브라우저 localStorage 기반 데이터 저장
